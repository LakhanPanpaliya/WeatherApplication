# Weather Application

A small client-side JavaScript weather app demonstrating fetching and displaying weather data in the browser.

**Features:**
- Simple UI driven by `index.html`.
- Fetches weather data from a public API (example implementation).
- Lightweight, no build step required — open in a browser.

**Files:**
- [index.html](JavaScript/WeatherApplication/index.html) — main app HTML and entry point.

**Usage:**
- Open the app by double-clicking `index.html` in your browser, or run a local HTTP server:

```bash
# from the WeatherApplication folder
python3 -m http.server 8000
# then open http://localhost:8000 in your browser
```

**Notes:**
- If the app uses an external API key, add it to the appropriate script or configuration before running.
- If you see CORS or network errors, run via a local server as shown above.
